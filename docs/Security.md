# DeskBridge 安全说明

桌桥使用 TLS 保护电脑之间的连接，默认开启加密及对端证书指纹验证。首次配对时，在对方电脑的“高级”页查看本机指纹，核对一致后才信任；证书改变后重新核对设备身份。

证书及私钥在本机生成，发行包不包含个人配置、私钥、设备信任记录或运行日志。配置和备份位置见[配置参考](Configuration.md)。普通设置保存或升级不需要主动重建证书；执行“重新生成证书”后，其他电脑可能需要重新信任。

Mac 发行包目前使用 ad-hoc 签名，尚无 Developer ID 公证；Windows 包尚无 Authenticode 签名。下载后核对同一 Release 的 SHA-256 清单，按系统正常流程授权安装及运行。

本项目未配置独立的公开安全公告或私密漏洞报告渠道。涉及潜在漏洞时，通过已有的私密联系渠道向仓库维护者提供最小复现；不要将尚未处理的漏洞细节、证书私钥、完整用户配置或未脱敏日志公开提交。普通连接问题可按[问题排查](Issues.md)整理材料。
