# DeskBridge 使用帮助

第一次使用请从[使用 README](../README.md)开始，按“来源端添加设备 → 接收端连接并信任 → 验证跨屏”的顺序完成配置。

| 需要做什么 | 界面入口 |
| --- | --- |
| 修改本机名称、来源／接收角色、来源地址 | 设备连接 → 连接设置 |
| 添加或移除电脑、设置别名 | 来源端 → 管理设备与控制… → 设备布局 |
| 调整已配置电脑的位置 | 设备连接首页拖动设备，或来源端完整布局编辑器 |
| 设置按键切屏、锁定光标 | 来源端 → 管理设备与控制… → 控制热键 |
| 配置剪贴板、切屏延迟和双击切屏 | 来源端 → 管理设备与控制… → 共享行为 |
| 适配 Ctrl／Command、添加应用规则、轻按 Shift | 接收端 → 快捷键映射 |
| 自动连接、后台运行和滚动方向 | 通用 |
| 查看本机指纹、连接端口、日志和证书维护 | 高级 |
| 复制版本与构建诊断信息 | 关于桌桥 |

配套版本支持远程布局及来源系统检测。接收端界面会标明需到来源端修改的项目，未同步的设置不会以本机默认值代替。

更多信息：[配置参考](Configuration.md) · [问题排查](Issues.md) · [安全说明](Security.md)。
