# DeskBridge 使用帮助

桌桥用于跨电脑共享键鼠，并按来源系统适配快捷键。两端应使用一致的协议和 TLS 设置。

- [配置参考](Configuration.md)：上游共享核心的配置文件说明。
- [问题排查](Issues.md)：整理版本、连接状态和复现步骤。
- [安全说明](Security.md)：个人分支与上游的报告范围。

配套 DeskBridge 服务端支持远程布局编辑和来源系统检测；旧服务端的能力可能不同，界面会显示可用状态。

上游核心技术资料见 [Deskflow Wiki](https://github.com/deskflow/deskflow/wiki)。
